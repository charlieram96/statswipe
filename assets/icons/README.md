# StatSwipe Icon Library

This folder contains custom SVG icons for the StatSwipe app.

## Icon Categories

- **Navigation**: Icons for bottom tab navigation
- **Game**: Basketball and game-related icons
- **Stats**: Statistics and chart icons
- **Social**: Friends and social features icons
- **UI**: General interface icons

## Naming Convention

Icons should follow this naming pattern:
- `category-icon-name.svg` (e.g., `nav-home.svg`, `game-basketball.svg`)

## Usage

To use these SVG icons in React Native, you can:
1. Use react-native-svg-transformer to import SVGs as components
2. Convert SVGs to icon fonts
3. Use them with libraries like react-native-svg

## Icon Guidelines

- Keep SVGs optimized and minimal
- Use consistent stroke widths
- Maintain a 24x24 viewBox for consistency
- Use currentColor for fill/stroke to allow color customization
